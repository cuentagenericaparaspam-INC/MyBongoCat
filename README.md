# Plugin Bongo Cat para OBS

Plugin de Live2D para OBS.

Overlay de Bongo Cat para OBS. Este plugin está basado en el **Live2D CubismNativeFrameWork** integrado y **OpenGL**.

# Compatibilidad

* Compatible con **OBS Studio versión 25.0.0 o superior**.

# Cómo utilizarlo

* Descarga [Bongo.Cat.zip](https://github.com/a1928370421/Bongobs-Cat-Plugin/releases/download/0.1.1/Bango.Cat.zip)
* Descomprime el archivo en el directorio raíz de OBS.
